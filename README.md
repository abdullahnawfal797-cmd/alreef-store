# الريف ستور | Al-Reef Store 🌿
منصة بوابات وصفحات هبوط عالية التحويل (High-Converting Landing Pages Engine) مخصصة للبيع عبر تيك توك، إنستغرام، وواتساب في العراق.

## المميزات الرئيسية
- **الدفع عند الاستلام (COD) بالدينار العراقي**: استمارة طلب فائقة السرعة تدعم اختيار كافة محافظات العراق (صلاح الدين، بغداد، أربيل، البصرة...).
- **طلب مباشر عبر واتساب**: رسائل ذكية مجهزة مسبقاً لرقم الهاتف المعتمد (`07723457175`).
- **تصميم كلاس مورفيزم (Glassmorphism)**: واجهات زجاجية راقية بألوان الشعار الأصلية (الكحلي الملكي، الزمردي الأخضر، والذهبي).
- **لوحة تحكم وإدارة كاملة (`/admin`)**:
  - إضافة وتعديل وحذف المنتجات بسهولة.
  - حساب هوامش الأرباح التلقائية.
  - إدارة وتحديث حالات الطلبات.
  - زر تأكيد واتساب مباشر مع الزبون العراقي بنقرة واحدة.
  - تصدير الطلبات بملف Excel/CSV لتسليمه لشركة التوصيل أو التاجر.

## التشغيل محلياً
```bash
npm install
node server.js
```
- المتجر العام: `http://localhost:3000`
- لوحة الإدارة: `http://localhost:3000/admin`
- مثال صفحة هبوط: `http://localhost:3000/p/smart-watch-ultra`

## خطوات النشر المجاني على الإنترنت (Render أو Railway)
1. رفع المشروع على GitHub.
2. الدخول إلى [Render.com](https://render.com) وعمل New Web Service.
3. اختيار مستودع GitHub وتعيين Start Command: `node server.js`.
4. مبروك! سيصبح لديك رابط دائم مجاناً.
